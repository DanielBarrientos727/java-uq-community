# Java UQ Community

Comunidad colaborativa dedicada al aprendizaje de la programación y las ciencias de la computación, con especial enfoque en los estudiantes de la Universidad del Quindío.

El proyecto busca reunir, organizar y compartir recursos académicos como talleres, diapositivas, apuntes, guías, ejercicios y documentación técnica, promoviendo el aprendizaje colaborativo, el intercambio de conocimientos y el desarrollo de habilidades en programación.

Un espacio abierto para aprender, compartir conocimiento y crecer como comunidad tecnológica.
